Commandes et livraison

Format international sans le + : 223 (Mali) puis le numéro.

Écrivez 0 si vous n’offrez pas la livraison.

Exemples : 24h, 48h, 2 à 3 jours, 1 semaine. Cette mention apparaît sur chaque carte produit, dans le bandeau du haut et dans l'accroche : elle est écrite une seule fois ici pour ne jamais se contredire.

Laissez vide si vous ne souhaitez pas annoncer de délai — la mention devient simplement « Échange possible ». N'annoncez que ce que vous pouvez tenir : une promesse non honorée sur les premières commandes se paie en bouche-à-oreille.

Textes affichés sur le site

Dites en une ou deux lignes ce que vous vendez et où.

Exemple : « Livraison offerte dès 50 000 FCFA ». Vérifiez que le montant correspond au réglage ci-dessus.
